API Reference

Note

This section documents the main API of the sft2d package.

Top-level functions and classes exposed by sft2d/__init__.py:

sft2d.create_grid(n_theta, n_phi)

Create a pole-to-pole finite-volume mesh.

sft2d.polar_average(field)

Force the two polar rows to be longitude-independent, in place.

sft2d.total_flux(field, grid[, signed])

Area-weighted flux over the whole sphere [Mx].

sft2d.Advection(grid, meridional_flow, ...)

Conservative MUSCL/TVD advection, y = -div(u B).

sft2d.Diffusion(grid, eta)

Conservative 5-point Laplacian, y = eta * lap(B).

sft2d.evolve(field0, grid, mf, dr, eta, num_days)

Integrate the SFT equation for num_days days.

sft2d.advect(u, operator, dt[, cfl])

Advance u by dt under advection, sub-cycling at the CFL limit.

sft2d.rkl2_step(u0, operator, dt[, s, ...])

Advance u0 by dt under du/dt = operator(u) using RKL2.

sft2d.initialize_field(grid[, field_type, ...])

Build an initial radial field on grid.

sft2d.correct_flux_multiplicative(f, grid)

Rescale each polarity so the map carries zero net flux.

sft2d.meridional_flow(grid[, peak_speed, ...])

Poleward meridional-circulation profile as the colatitude velocity u_theta.

sft2d.meridional_flow_latitude(grid[, ...])

Same flow as meridional_flow(), but as the latitude velocity v_lat.

sft2d.differential_rotation(grid[, ...])

Differential-rotation angular velocity Omega(theta) [rad/s].

sft2d.make_bmr(grid, lat_deg, lon_deg, flux_mx)

Return the 2-D radial-field increment [G] of one flux-normalised BMR.

sft2d.make_bmr_yeates(grid, lat_deg, ...[, ...])

Return the 2-D radial-field increment [G] of one Yeates-style bipole.

sft2d.insert_bmr(field, grid, lat_deg, ...)

Add one BMR to field in place and return it.

sft2d.balance_flux(f, grid)

Rescale each polarity so the map carries zero net flux.

sft2d.joys_law_tilt(lat_deg[, coeff, form])

Joy's law tilt angle [deg] for a BMR at latitude lat_deg.

sft2d.hale_leading_sign(lat_deg, cycle_number)

Sign (+/-1) of the leading (equatorward) polarity following Hale's law.

sft2d.ARSource(table, start_date[, ...])

sft2d.SHARPSource(catalogue, start_date[, ...])

Callable source(day, field, grid) driven by a SHARPS BMR catalogue.

sft2d.SHARPPatchSource(catalogue, nc_dir, ...)

Callable source(day, field, grid) that inserts observed AR patches.

sft2d.solar_cycle_number(date)

Return the solar cycle number active on date (a datetime/Timestamp).

sft2d.calculate_usflx(all_br_data, grid)

Total unsigned flux [Mx].

sft2d.calculate_net_flux(all_br_data, grid)

Net (signed) flux [Mx].

sft2d.calculate_dm(all_br_data, grid)

Axial dipole moment [G].

sft2d.calculate_polar_field(all_br_data, grid)

Area-weighted mean radial field in each polar cap [G].

sft2d.calculate_polar_flux(all_br_data, grid)

Signed magnetic flux in each polar cap [Mx].

sft2d.cap_areas(grid, pol_cap_extent_deg[, cm])

Per-cell areas of the north and south polar caps, as (n_theta, 1).

sft2d.plot_bfly(bfly_sft, grid[, bmax, ...])

Plots the butterfly diagram of the surface magnetic field.

sft2d.plot_mag(b_data, grid[, bmax, ...])

Plots the magnetic field strength at the solar surface.
